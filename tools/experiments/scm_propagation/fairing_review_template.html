What changes

The earlier C2 prototype smooths support weights and local bone transforms. It still treats each curve point largely independently. The new experiment reconstructs the curve as a whole: remain near those support goals, retain the transformed original curvature, and satisfy anatomical endpoints exactly. One cached linear factorization, three direct back-substitutions per curve. No routing, planner, iterative collision recovery, or inflation change. The value 0.20 controls the smoothing scale in normalized rest arc length; it is a tested candidate, not a selected product default.

Wider support blending alone improves some inflation folds but increases base crossings (28 to 40). Reconstruction is the more promising direction in this case. Stronger reconstruction reduces peak automatic support response; it does not ignore Ribs. The third fiber retains about 77% of its mean Ribs-induced displacement in an ablation.

Limits and next qualification

This fixture has three open Polylines with 73 samples each. Wider sampling, authored corners, interior anatomical pins, junctions, loops, shared consumers and nonrigid anatomical edits still need qualification. The probe uses a small dense factorization; its matrix is banded, allowing a compact implementation if this approach is selected for production. There is no guarantee of obstacle clearance or valid inflated surfaces for arbitrary edits.

Raw evidence: geometry and curve metrics, timing medians, all timing samples, preparation and invariants, every contacted segment, Ribs ablation, runtime profile.
