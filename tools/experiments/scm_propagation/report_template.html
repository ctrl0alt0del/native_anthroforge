Observed shape checks

The middle Fiber’s largest adjacent-sample gap falls from 1.992 to 0.171 model units. Explicit endpoints remain exact. Neutral shape and a rigid-motion test agree to below 7×10⁻¹⁵.

Final transverse self-crossing pairs: 245 current → 39 experimental; endpoint-only ROUTED final: 0. Its uncropped base still has 27 crossing pairs. No collapsed faces were detected. These checks exclude touching/coplanar contact and containment; they are advisory.

What the prototype computes

Cached arc-length weights with a 20% rest-length kernel; eight regional affine maps per support, each fit from 64 fixed bind-topology vertices using small 3×3 matrix operations; C2 cubic B-spline interpolation of regional maps; exact endpoint corrections. No iterative path or global deformation solve. The experiment verifies unchanged parent connectivity before using vertex correspondence.

Ribs influence remains active: peak middle-Fiber Ribs weight is 0.627, rather than zero. Coherent transport and wider pin transitions change how it is distributed. First prototype maps used linear interpolation; visible regional joins prompted the C2 interpolation used in the final results.

Limits and reproducibility

This qualifies one SCM edit only. The remaining bulge and 39 crossings mean this is not a complete shape fix. Source Spine first-segment contact predates the edit and remains in the advisory checks. The experiment does not promise collision-free deformation or general large-deformation correctness.
